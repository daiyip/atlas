# Contributing

Corrections and new data are the most welcome contributions: a wrong date, a misplaced city, a missing event. Open
an issue with the item and a source, or a pull request that changes the data and cites the source in its
description.

New features for your own use usually belong in a [data pack or plugin](docs/plugins.md) rather than in the
engine. If the pack and plugin interfaces cannot do what you need, open an issue saying what is missing; that is
how the interfaces grow.
